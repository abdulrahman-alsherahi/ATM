# 💳 ATM Simulation (C++)

Simple **ATM system simulation** built using **C++**.
Runs in the terminal and allows basic banking operations.

## ✨ Features

* 🔐 Password authentication
* 🔁 3 login attempts
* 💰 Check balance
* ➕ Deposit money
* ➖ Withdraw money
* ⚠️ Prevents withdrawing more than available balance
* 📋 Interactive ATM menu

## 🖥️ Example Menu

```
========== ATM MENU ==========
1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit
==============================
```



## 🛠️ Built With

* C++
* iostream
* Loops & Conditions
